# tybird API - Dokumentation

Referenz für App-API, Support-API und den MCP-Server für Claude, dargestellt mit [Scalar](https://github.com/scalar/scalar) über GitHub Pages: <https://billiton-gmbh.github.io/tybird-api/>

`openapi.yaml` ist die einzige Quelle. Änderungen kommen als Änderungsantrag; nach dem Merge auf `main` aktualisiert GitHub Pages die Seite ohne Build. Jede Änderung erhöht `info.version` und ergänzt eine Zeile im Changelog; das prüft `.github/workflows/changelog-guard.yml`.

Vorschau: `npx serve .`
